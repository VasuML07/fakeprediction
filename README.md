# Fake Job Prediction System 🕵️‍♂️🚫

An NLP-powered machine learning solution to detect fraudulent job postings. This project uses deep learning and text analysis to distinguish between legitimate opportunities and scams, helping job seekers stay safe.

## 📂 Project Structure
* **app.py**: The main application file (likely Streamlit/Flask) for the web interface.
* **fake_job_model.pkl**: The trained classification model.
* **tfidf_vectorizer.pkl**: The vectorizer used to process text input.
* **train_model.py**: The script used to train the model from scratch.
* **requirements.txt**: List of Python dependencies.
